G15 System Monitor 1.0.0

Панель Windows x64 для LCD-дисплея Logitech G15. Это не официальный продукт Logitech.

.NET входит в комплект. Для физического дисплея требуются Logitech Gaming Software (LGS) и библиотека x64 LogitechLcd.dll из LCD SDK. Приложение ищет её в установленной LGS. Если библиотека отсутствует, законно полученную копию x64 из Logitech SDK можно поместить рядом с G15Dashboard.exe. LGS, эта библиотека и драйверы не входят в комплект и не устанавливаются автоматически. Без LCD доступен предварительный просмотр.

Для некоторых датчиков требуются PawnIO и права администратора. Отсутствующие значения отображаются как --; если допустимого значения FPS нет, число и подпись FPS скрываются.

Приложение устанавливается в Program Files. Отдельное запланированное задание позволяет запуск с повышенными правами без повторных запросов UAC. Оно относится к учётной записи администратора, выполняющей установку, в том числе если введены данные другого администратора. Автозапуск необязателен и по умолчанию отключён. Другие учётные записи могут запускать EXE напрямую и подтверждать повышение прав.

Ярлык на рабочем столе называется G15 System Monitor (установлено). При смене языка с созданием ярлыка ярлык установки на другом языке заменяется. Ярлыки версий для разработки сохраняются. Перед запуском закройте старые версии через область уведомлений.

Для обновления повторите установку; предыдущий выбор параметров задания сохраняется. Удаление через Windows удаляет установленные файлы, ярлыки и собственное задание. Пользовательские данные, LGS, PawnIO и файлы, добавленные вручную, сохраняются.

Можно выбрать язык установки и удаления; по умолчанию выбран английский. Интерфейс приложения остаётся немецким. Эти сведения также устанавливаются в Setup\Languages.

Установщик не подписан. Общие аппаратные испытания на всех поддерживаемых устройствах Intel, AMD и NVIDIA не проводились. Лицензии и ссылки на исходный код: папка licenses.
