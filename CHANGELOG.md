# Changelog

## 1.0.0 — prepared 2026-10-17

- Windows x64 dashboard for the Logitech G15 monochrome LCD and desktop preview.
- CPU/GPU usage and temperatures, RAM/VRAM usage, foreground-application FPS, tray controls and diagnostics.
- Fixed four-bar layout, YYYY.MM.DD date and centered clock; missing FPS number and label hidden together.
- Reusable rendering/sensor buffers, isolated CSV parsing and 20 regression checks.
- Self-contained installer with optional autostart, setup-owned scheduled task, single-instance/shutdown support and LCD reconnection attempts.
- Twelve installer languages, with English selected by default.
- Portable source package with third-party notices and no proprietary Logitech DLL or machine-specific deployment files.

The release is unsigned. Original project licensing is not yet selected. Translation review and additional target-hardware/installation checks remain pending as described in README.md.
